# SideQuest

SideQuest is a student-focused micro-task marketplace designed to connect students with paid opportunities, short-term gigs, and skill-building tasks. The platform provides a space where students can earn, gain practical experience, and develop their skills by completing real-world tasks posted by individuals, organizations, or fellow students.

## Features

* User authentication and account management
* Create and post micro-tasks
* Browse available opportunities
* Task application and participation
* Skill-focused task categories
* Student-friendly interface
* Responsive design for desktop and mobile devices

## Why SideQuest?

Many students look for opportunities to gain experience, build their portfolios, and earn some income while studying. At the same time, individuals and organizations often need help with small tasks that do not require full-time hiring.

SideQuest bridges this gap by creating a platform where students can discover meaningful opportunities while task creators can quickly find motivated contributors.

## Tech Stack

* Frontend: React.js
* Backend: Node.js, Express.js
* Database: MongoDB
* Authentication: JWT / Secure Authentication
* Styling: Tailwind CSS
